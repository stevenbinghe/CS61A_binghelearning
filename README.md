## 项目介绍

### [Project1:Hog](/Project_1_Hog/)

#### 游戏规则

在Hog中，两名玩家轮流轮流，争夺第一个结束回合的人，总分为GOAL，默认为100分。每回合，当前玩家选择你要扔出骰子的个数（0~10），最多可掷10个骰子。该玩家本回合的得分为骰子总点数之和。然而，掷骰过多的玩家将面临以下风险：
1. Sow Sad 如果任何骰子结果为1，则对于回合来说当前玩家的得分为1，无论掷出的其他点数如何.示例如下:
  - 示例1：当前玩家掷7个骰子，其中5个是1。他们该回合得分为1
  - 示例2：当前玩家掷4个骰子，全部是3。因为 Sow Sad没有发生，他们该回合得分为12
2. Boar Brawl(可选) 选择掷零骰的玩家得三次分 对手得分的十位数和 当前玩家得分的一位数字，或以较高者为1。 数字1表示最右边的数字，数字10表示 右边第二位的数字。如果某玩家的得分是个位数（低于小于 10），该玩家得分的十位数为0。示例如下:
  - 示例1:
    - 当前玩家有21分，对手有46分，当前玩家选择掷零骰子。
    - 对手得分的十位数字是4，当前玩家得分的个位数字是1
    - 因此，玩家可以获得积分`3*abs(4-1)=9`
  - 示例2:
    - 当前玩家有45分，对手有52分，当前玩家选择掷零骰子。
    - 对手得分的十位数字是5，当前玩家得分的个位数字也是5。
    - 由于`3*abs(5-5)=0`,当前玩家获得1分
  - 示例3： 
    - 当前玩家有2分，对手有5分，当前玩家选择掷零骰子。
    - 对手得分的十位数字是0，当前玩家得分的一数字是2。
    - 因此，玩家可以获得积分`3*abs(0-2)=6`

3. Sus Fuss(可选) 如果一个数字恰好满足3或4个因数(包括1和数字本身)，我们称之为可疑。 如果掷骰后当前玩家的分数是可疑数字，其分数会立即上升到比当前分数最接近的质数。示例如下:
  - 示例1:
    - 玩家有14分，掷2个骰子可获得7分。 他们的新分数是21，包含4个因数：1、3、7和21。 因此，21分是可疑的，玩家得分立即提高到23分，即下一个质数。
  - 示例2:
    - 得分为63的玩家掷5个骰子，回合获得1分。 他们的新得分是64（Sow Sad），包含7个因素：1、2、4、8、16、32、64。由于64分不算可疑，玩家的分数保持不变。
  - 示例3:
    - 玩家有49分，掷5个总分18分的骰子。他们的新分数是67，是质数，包含两个因子：1和67。 由于67分不算可疑，玩家的分数保持不变。
